## Matchmaker Overhaul
Matchmaker remade from scratch!

# Reconnect Mk0.5
If you fail to connect to the server *at all*, you will be automatically reconnected to the match after logging back in!
*If you did manage to connect, but then lost connection, you will not be able to reconnect. This is due to some technical issues in the current game build.*
In the future, we want to fully implement reconnect, so you will be able to reconnect even if you lost connection mid-match.
